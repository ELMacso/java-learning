# Literals #

## Numeric literals ##

- Integer numbers: byte, short, int, long. 
- Decimal numbers: double, float

## Character literals ##
- Characters: char. Special character: \b - backspace. \n - new line. \t - tab. 
- String: string. ""

## Logical literals ##
- boolean: true or false.

## Type less declaration ##
```
        var intro = "Hello Java!";
        var sum = 11.0;
```
The variable must be initialized.
